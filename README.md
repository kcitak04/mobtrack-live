# MOBTRACK Live

The MOBTRACK mobile music tracker, reskinned with an Ableton Live-inspired look: flat greys, an orange accent, coloured track title bars and a sans-serif interface. It is an unofficial fan skin and is not affiliated with Ableton.

It works exactly like [MOBTRACK](https://kcitak04.github.io/mobtrack/): 8 tracks, a sampler with warp and slicing, 4 synths, a mixer with effects, automation, resampling, WAV and MOD export.

## Open / install

Open https://kcitak04.github.io/mobtrack-live/ in Chrome. To install it as an app on Android, use **INSTALL APP** in the FILE tab or Chrome's menu ⋮ → **Install app**.

It installs next to the original MOBTRACK. Each edition keeps its own autosave.
