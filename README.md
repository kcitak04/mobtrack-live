# DATTRACK Studio

The DATTRACK mobile music tracker with a flat dark-grey look: grey surfaces, an orange accent, coloured track title bars and a sans-serif interface.

It works exactly like [DATTRACK](https://kcitak04.github.io/mobtrack/): 8 tracks, a sampler with warp and slicing, 4 synths, a mixer with effects and a master fader, automation, resampling, the Sample Lab, and WAV / AIFF / FLAC / Opus / MOD export.

## Open / install

Open https://kcitak04.github.io/mobtrack-live/ in Chrome. To install it as an app on Android, use **INSTALL APP** in the PREF tab or Chrome's menu ⋮ → **Install app**.

It installs next to DATTRACK. Each edition keeps its own autosave.

## Android app (APK)

Download `DATTRACK-Studio.apk` from the [latest release](https://github.com/kcitak04/mobtrack-live/releases/latest) on your phone and open it. It installs as **DATTRACK Studio**, a separate app next to DATTRACK, and works fully offline.
